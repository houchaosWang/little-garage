# 小小维修站

给4-5岁孩子的学前学习兴趣引导APP。孩子扮演维修站师傅，帮各种车辆客人修理，学习内容藏在修车动作里。**15个小游戏**覆盖数感、计数、加减、数轴、规律、分类、图形、方位、比较、认字、描字、音节与字音对应；每个游戏约6级，由看不见的难度引擎按孩子的表现自动升降，学过的级别会被悄悄抽查。

设计依据：教育部《3-6岁儿童学习与发展指南》、《义务教育数学课程标准（2022年版）》、2024 人教版/统编版一年级教材，以及早期数学与识字研究（详见 `docs/phase6-design-rationale.md` 与《家长手册3.1》）。

## 15个游戏一览

| 游戏 | 学什么 | 最难一级 |
|---|---|---|
| 装轮胎 | 计数、按数取物 | 不报数、自己数出8–15个再按绿勾 |
| 加油 | 认数字 | 1–15 |
| 换车灯 | 颜色 | 6选1 |
| 石头算数 | 加减、接着数、凑十 | 十格框凑十（20以内进位加法） |
| 认字搬箱 | 识字（40字） | 6选1，干扰都是形近字 |
| 描字 | 笔顺 | 地你我他雨花草虫鸟鱼 |
| 形状对孔 | 平面图形 | 5种、零件转了方向 |
| 比大小 | 长短、大小 | 错开摆放、有陷阱 |
| 闪灯看数 | 速视（一眼看出几个） | 十格阵看还差几个满十 |
| 找规律 | 重复规律 | 找出重复的那一小段 |
| 数字赛道 | 心理数轴、接着数 | 0–20 估位置 / 还差几格到终点 |
| 停车场故事 | 加减的意义、比多少 | 蓝车比红车多（少）几辆，蓝车有几辆 |
| 零件分拣 | 分类、规则切换 | 颜色×形状交叉分四个筐 |
| 方位摆放 | 上下里外前后左右 | 两步指令 / 照示意图摆 |
| 车名拍拍 | 音节意识、一字一音、语素 | 去掉中间的字 / 分清"车灯"和"警车"（车字在前还是在后） |

## 装到iPad上（推荐：家里局域网，不需要梯子）

电脑和 iPad 连同一个路由器就行。**装完之后电脑可以关机、iPad 可以断网，游戏照样玩。**

1. **电脑上**：双击项目根目录的 `启动维修站服务器.cmd`（或命令行 `node tools/serve.mjs`）。
   窗口里会打印一个带 ★ 的地址，例如 `http://192.168.0.42:8080`。
   如果 Windows 弹出防火墙窗口，勾选 **专用网络** 并允许。
2. **iPad 上**：Safari 打开那个 ★ 地址，会出现《安装向导》，照着四步做：
   装证书 → 打开信任开关 → 打开游戏 → 添加到主屏幕 → 等语音进度装满。
3. 之后孩子只点桌面上的“维修站”图标就行。

> 为什么要装证书：Service Worker 只在 HTTPS 下才注册，没有它就不能离线玩。
> 局域网没有公网域名，只能自签证书；根证书只装这一次，以后电脑换IP也不用重装。

**建议**在路由器里给电脑设一个固定IP（DHCP 静态分配）。地址变了的话：孩子已装好的那份进度不会丢、也能继续玩，但要推更新就得重新走一遍安装向导（换地址 = 换网站 = 换一份存档，记得先用下面的“存档搬家”备份）。

装好局域网这份之后，**把 iPad 上旧的那个（github.io 装的）图标删掉**，否则两个图标各有一份独立进度，孩子点错就白练了。

备用线路（需要梯子）：https://houchaoswang.github.io/little-garage/

### iPad 连不上电脑时按顺序查

1. iPad 和电脑是不是同一个路由器？（iPad 用蜂窝网络、或连了访客WiFi都不行）
2. 服务器窗口还开着吗？窗口一关服务就停了。
3. 电脑IP变了吗？重新跑一遍服务器，看窗口里打印的 ★ 地址是否还是原来那个。
4. 防火墙：这台电脑当前三个配置文件都是关闭状态，所以不会拦。
   万一以后 Windows 自动把防火墙打开了，就会拦 —— 因为“以太网”被系统归成了**公用网络**。
   届时二选一：把该网络改成**专用**，或给 `node.exe` 放行入站（管理员 PowerShell）：
   `New-NetFirewallRule -DisplayName "小小维修站" -Direction Inbound -Program "$((Get-Command node).Source)" -Action Allow -Profile Any`
5. 路由器开了“AP隔离/客户端隔离”的话，无线设备看不到有线设备，需要在路由器里关掉。

## 日常

- 每天默认营业4单（约15分钟），修完自动打烊，次日自动开张。每单2个学习小游戏（偶尔加一个洗车），玩得少的游戏更容易被抽到。
- **家长面板**：两根手指在屏幕上长按1.8秒。可调每日单数（1-12）、今天重新营业、看掌握地图（14个技能）与游戏统计、导出报告、**存档备份/搬家**、清空进度。
- 数据不出家门：只存在 iPad 上，以及（从家里电脑装的那份）同步到这台电脑的 `data/progress/`。任何时候都不会发到互联网——从 github.io 装的那份一个字节都不发。

### 孩子的进度自动同步到这台电脑

从家里电脑装的那份，每次存档（每局结束、每单结束、切出APP时）都会顺手发一份给这台电脑，攒3秒只发最新的。电脑关着也没关系：发不出去就静默放弃，下次再发，孩子完全无感。

- 服务器窗口每收到一次会打印一行 `●`，写明累计多少单、各技能几级。
- 数据落在 `data/progress/latest.json`（最新）和 `data/progress/daily/日期.json`（每天最后一份，用来看每天的变化）。`data/` 已 gitignore——仓库是公开的，绝不会被提交。
- **家里不止一台 iPad 时**：每台 iPad 是各自独立的一份进度（不会自动合并）。电脑上 `data/progress/devices/` 里每台各存一份；`latest.json`（主进度、报告读它）只跟着"同一台"或"进度不少于它的那台"走，一台空白的 iPad 打开游戏不会把孩子的主进度冲掉。想让孩子换到另一台 iPad 玩，用下面的"存档搬家"把进度搬过去。
- 看人话报告：`node tools/progress-report.mjs` —— 各技能等级、每个游戏的总账、每天的等级变化、最近30道题（级别/错几次/求助/用时/什么题），以及“偏简单 / 吃力 / 封顶”的判断。
- 家长面板里能看到“已同步到电脑 · 今天 14:05”，也可以点旁边的 `立即同步` 马上发一份。

### 存档搬家（换地址、换iPad、或想留个底）

家长面板 → **存档备份 / 搬家** → 上面那段就是全部进度：
- 备份：点 `复制存档`，粘到微信/备忘录存着。
- 恢复：把备份粘进下面的框 → `导入并覆盖当前进度`（要按两次确认）。

## 更新内容（在电脑上）

1. 改代码；每次内容更新必须把 `sw.js` 里的 `VERSION` 改成新值（如 `garage-v16`），否则 iPad 拿不到新资源；新增的 js 文件与语音也必须加进 `sw.js` 的 `ASSETS` / `AUDIO_NAMES`（`tests/levels.test.mjs`、`tests/integration.test.mjs`、`tests/syllable.test.mjs` 会查出漏加和拼错）。
   要照顾老 iPad（iOS 13.4 起）：CSS 别用 `inset` 和 flex 的 `gap`，JS 别用 iOS 13.4 没有的新语法——`tests/compat.test.mjs` 会查。
2. 启动服务器（局域网这份不用 push，改完就生效）；iPad 打开APP等十几秒、划掉再打开即拿到新版。
   如果用 GitHub Pages 那份：`git push` 后约1分钟生效。
3. 发布后自检：电脑浏览器打开 `http://localhost:8080/?sw=1`，开发者工具 → Application → Cache Storage
   应看到 `garage-v15`（当前版本号）缓存且 **438个条目** —— 这一步能发现“某个文件漏提交导致离线缓存整体失效”。
   自检完打开 `http://localhost:8080/?sw=0` 注销，别把缓存留在 8080 端口上妨碍别的项目。

## 开发

- 局域网/本地服务器：`node tools/serve.mjs`
  - `http://localhost:8080` → 直接是游戏，且**不注册** Service Worker（避免缓存干扰调试）
  - `http://<局域网IP>:8080` → 给家长的安装向导
  - `https://<局域网IP>:8443` → 真正给 iPad 玩的地址（自签证书，`certs/` 自动生成且已 gitignore）
- 跑测试：`node --test tests/*.test.mjs` （注意：本机不要用目录形式 `node --test tests/`）
- 生成语音：`python tools/gen-voice.py 名字1 名字2`（只生成指定几条；不带参数是全量重生成，会让所有 mp3 字节都变）。需先 `python -m pip install edge-tts`；本机 pip 不在 PATH 上。
- 重新生成图标：PowerShell 运行 `tools/gen-icons.ps1` （仅Windows，System.Drawing）
- 技术栈：纯 HTML + SVG + vanilla JS（ES Modules），零框架、零依赖、零构建。证书靠 Git 自带的 openssl 生成。
- 描字笔画数据与渲染：[hanzi-writer](https://github.com/chanind/hanzi-writer)（MIT License，已离线打包于 vendor/）
