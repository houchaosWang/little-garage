# 小小维修站

给4-5岁孩子的学前学习兴趣引导APP。孩子扮演维修站师傅，帮各种车辆客人修理，数数、颜色、形状、认字、描字、算数等学习内容藏在修车动作里。设计文档见 `docs/`。

## 装到iPad上（推荐：家里局域网，不需要梯子）

电脑和 iPad 连同一个路由器就行。**装完之后电脑可以关机、iPad 可以断网，游戏照样玩。**

1. **电脑上**：双击项目根目录的 `启动维修站服务器.cmd`（或命令行 `node tools/serve.mjs`）。
   窗口里会打印一个带 ★ 的地址，例如 `http://192.168.0.42:8080`。
   第一次启动 Windows 会弹防火墙窗口 —— 勾选 **专用网络** 并允许。
2. **iPad 上**：Safari 打开那个 ★ 地址，会出现《安装向导》，照着四步做：
   装证书 → 打开信任开关 → 打开游戏 → 添加到主屏幕 → 等语音进度装满。
3. 之后孩子只点桌面上的“维修站”图标就行。

> 为什么要装证书：Service Worker 只在 HTTPS 下才注册，没有它就不能离线玩。
> 局域网没有公网域名，只能自签证书；根证书只装这一次，以后电脑换IP也不用重装。

**建议**在路由器里给电脑设一个固定IP（DHCP 静态分配）。地址变了的话：孩子已装好的那份进度不会丢、也能继续玩，但要推更新就得重新走一遍安装向导（换地址 = 换网站 = 换一份存档，记得先用下面的“存档搬家”备份）。

装好局域网这份之后，**把 iPad 上旧的那个（github.io 装的）图标删掉**，否则两个图标各有一份独立进度，孩子点错就白练了。

备用线路（需要梯子）：https://houchaoswang.github.io/little-garage/

## 日常

- 每天默认营业4单（约15分钟），修完自动打烊，次日自动开张。
- **家长面板**：两根手指在屏幕上长按1.8秒。可调每日单数（1-12）、今天重新营业、看掌握地图与游戏统计、导出报告、**存档备份/搬家**、清空进度。
- 所有数据只存在 iPad 本地，任何时候都不上传；导出/备份都得家长手动点。

### 存档搬家（换地址、换iPad、或想留个底）

家长面板 → **存档备份 / 搬家** → 上面那段就是全部进度：
- 备份：点 `复制存档`，粘到微信/备忘录存着。
- 恢复：把备份粘进下面的框 → `导入并覆盖当前进度`（要按两次确认）。

## 更新内容（在电脑上）

1. 改代码；每次内容更新必须把 `sw.js` 里的 `VERSION` 改成新值（如 `garage-v11`），否则 iPad 拿不到新资源。
2. 启动服务器（局域网这份不用 push，改完就生效）；iPad 关掉APP重开两次即拿到新版。
   如果用 GitHub Pages 那份：`git push` 后约1分钟生效。
3. 发布后自检：电脑浏览器打开 `http://localhost:8080/?sw=1`，开发者工具 → Application → Cache Storage
   应看到 `garage-v10`（当前版本号）缓存且 **214个条目** —— 这一步能发现“某个文件漏提交导致离线缓存整体失效”。
   自检完打开 `http://localhost:8080/?sw=0` 注销，别把缓存留在 8080 端口上妨碍别的项目。

## 开发

- 局域网/本地服务器：`node tools/serve.mjs`
  - `http://localhost:8080` → 直接是游戏，且**不注册** Service Worker（避免缓存干扰调试）
  - `http://<局域网IP>:8080` → 给家长的安装向导
  - `https://<局域网IP>:8443` → 真正给 iPad 玩的地址（自签证书，`certs/` 自动生成且已 gitignore）
- 跑测试：`node --test tests/*.test.mjs` （注意：本机不要用目录形式 `node --test tests/`）
- 重新生成语音：`python tools/gen-voice.py` （需先 `python -m pip install edge-tts`；本机 pip 不在 PATH 上）
- 重新生成图标：PowerShell 运行 `tools/gen-icons.ps1` （仅Windows，System.Drawing）
- 技术栈：纯 HTML + SVG + vanilla JS（ES Modules），零框架、零依赖、零构建。证书靠 Git 自带的 openssl 生成。
- 描字笔画数据与渲染：[hanzi-writer](https://github.com/chanind/hanzi-writer)（MIT License，已离线打包于 vendor/）
