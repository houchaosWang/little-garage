# 阶段2a：真机反馈修复 + 三个新微游戏 + 家长面板

依据：家长真机试用反馈（2026-08-31晚）：①画面加载慢；②一轮玩完永久打烊无法再试；③操作快于语音时流程被语音阻塞；④游戏种类少、单局太短；⑤要求双指长按调出隐藏设置（每日单数）。

任务与验收（完整代码以各任务派发提示词为准，逐任务实现+审查）：

- **A. 语音可打断 + 流程不阻塞 + SW韧性**：audio.js 增加 `sayNow()`（世代计数打断当前及排队语音）；装胎计数、气泡指令、闲置提示改用 sayNow；主流程 praise/goodbye 不再 await，与欢呼/驶出动画并行；sw.js install 改 `Promise.allSettled` 逐个缓存、fetch 未命中时联网成功后回填缓存（边玩边补）。VERSION→garage-v4。
- **B. 家长面板**：js/parent.js。双指按住≈1.8秒（位移>40px或第三指取消）弹出覆盖层：每日营业单数步进（1-12，实时保存）、今天重新营业（清除当日计数并刷新）、清空全部进度（二次确认）、关闭。任何场景可调出（含睡觉画面）。store 增加 `wipe()`、`reopenToday(data)` 及测试。
- **C. 出题器扩展**：taskgen 增加 `genFuelTask`（数字认读 1-5/3-8/5-10）、`genLightsTask`（颜色选项 3/4/5 个，含车身色恰一次）；store 默认技能增加 numerals、colors（旧档 mergeDefaults 自动补全，含测试）。
- **D. 加油微游戏** game-fuel.js：按住油枪数字上涨，到目标数字松手；过冲→温柔重来并计1错误；不足→语音鼓励继续。技能 numerals。
- **E. 车灯微游戏** game-lights.js：车头虚线灯座，底部若干彩色灯泡，点中与车身同色者飞入点亮；点错→抖动+语音+计1错误。技能 colors。
- **F. 洗车微游戏 + 编排** game-wash.js：车身泥点用手指擦除，全清→星光；无学习点。main.js 引入 GAME_DEFS 表驱动：每单=2个不同学习游戏（tires/fuel/lights 随机），25%概率追加洗车；每环节独立气泡+语音+技能记录，首环节前置客人开场白。
- **G. 语音与发布**：gen-voice.py 增 10 条台词（fuel/lights/wash 的任务、纠错、闲置语）；preload 33条；SW ASSETS=50 项；README 更新；VERSION→garage-v5；部署并线上验证。

验收：本地+线上完整跑通"两环节一单"；打断语音即时生效（装胎瞬时念数）；双指长按各场景可调出面板并即时生效；旧存档升级不丢进度；20+新增测试全绿；缓存 50 条目。
