# 阶段3：难度提升 + 算数讲解 + 认字 + 描字

依据：真机反馈（孩子觉得太简单），家长要求：更高难度、更多游戏方式（认字、描字、基础算数且带讲解）。

## 范围

- **A. 纯逻辑扩展**（taskgen/store/tests）：
  - 现有三游戏加第4级：轮胎 L4 数量8-12（架上上限14）；加油 L4 目标8-15（表满格15）；车灯 L4 六色全选项。
  - 新出题器：`genMathTask`（math技能，L1加法≤5 / L2加法≤10 / L3减法≤10 / L4十以内加减混合；3个数字选项含正解）、`genHanziTask`（literacy技能，20常用字表 CHARSET，L1六字池2选1 / L2十二字池3选1 / L3二十字池4选1）、`genTraceTask`（tracing技能，按笔画数分三级选字）。
  - store 默认技能补 math/literacy/tracing（旧档自动补全，含测试）。
- **B. 语音扩包**（gen-voice +45条）：num-11..15；算数连接词（加/减/等于/等于几/我们一起数一数/对啦/再装上/拿走/任务与闲置语）；char-1..20（二十个字的单字读音，按索引命名规避文件名中文）；描字与认字的任务/纠错/闲置语。
- **C. 第三方描字库**（tools/get-hanzi.mjs）：下载并入库 vendor/hanzi-writer.min.js（MIT，约34KB）与 vendor/hanzi-data/*.json（20字笔画数据）；index.html 前置加载。
- **D. 现有游戏运行时升级**：轮胎圈半径随数量自适应、货架2×7布局；加油表按 task.max 缩放；车灯6选项布局复核。
- **E. 石头算数** game-math.js：木箱石头可视化（加法滚入/减法搬走）+ 三数字牌作答；答错→"一起数"讲解（石头逐颗高亮与语音逐数同步）后重答；答对→简短复述讲解。
- **F. 认字搬箱** game-hanzi.js：字箱点选，正确飞入货斗，错误抖动温柔提示。
- **G. 描字** game-trace.js：HanziWriter quiz 模式（笔顺校验、两次写错出提示描红），HTML覆盖层卡片；错≥3计1错误（宽容）。
- **H. 编排与发布**：游戏池扩为 tires/fuel/lights/math/hanzi/trace 六选二+25%洗车；GAME_DEFS 补三项；preload 核心22条；SW ASSETS≈123项；VERSION→garage-v7；README；部署+线上验证。

验收：新旧六游戏均可完整游玩且语音正确；讲解逐颗数石头与语音同步；描字笔顺校验生效；旧存档无损升级并自动获得新技能；测试≥32全绿；线上缓存装满。

完整代码以任务派发提示词为准，逐任务实现+审查（与阶段1/2a同流程）。
